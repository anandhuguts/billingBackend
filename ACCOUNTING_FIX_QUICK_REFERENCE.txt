**Check for Discount Entries (Should be 0):**
  
  SELECT COUNT(*) 
  FROM journal_entries
  WHERE description LIKE '%discount%'
    AND reference_type = 'invoice'
    AND created_at > NOW() - INTERVAL '1 day';

**Check Inventory Stock Values:**

  SELECT 
    p.name,
    i.quantity,
    i.stock_value,
    (i.stock_value / NULLIF(i.quantity, 0)) as avg_cost
  FROM inventory i
  JOIN products p ON i.product_id = p.id
  WHERE i.tenant_id = 'YOUR-TENANT-ID'
    AND i.quantity > 0
  ORDER BY i.stock_value DESC
  LIMIT 10;

**Check COA Account Types:**

  SELECT name, type
  FROM coa
  WHERE tenant_id = 'YOUR-TENANT-ID'
    AND name IN (
      'Cash', 'Bank', 'Inventory', 'Accounts Payable',
      'VAT Payable', 'Sales', 'Cost of Goods Sold'
    )
  ORDER BY type, name;

  Expected:
    Cash → asset
    Bank → asset
    Inventory → asset
    Accounts Payable → liability
    VAT Payable → liability
    Sales → income
    Cost of Goods Sold → expense
