This breaks:
  ❌ Balance sheet
  ❌ Accounting equation (Assets = Liabilities + Equity)
  ❌ Purchase liability tracking
  ❌ Supplier payables reporting

Verify journal entries:

  SELECT 
    dr.name as debit,
    dr.type,
    cr.name as credit,
    cr.type
  FROM journal_entries je
  JOIN coa dr ON je.debit_account = dr.id
  JOIN coa cr ON je.credit_account = cr.id
  WHERE je.reference_type = 'purchase'
  ORDER BY je.created_at DESC
  LIMIT 2;

Expected:
  ✅ debit: Inventory (asset)
  ✅ credit: Accounts Payable (liability)  ← THIS IS CRITICAL

Check COA types:

  SELECT name, type 
  FROM coa 
  WHERE LOWER(name) IN (
    'accounts payable',
    'inventory',
    'vat input',
    'cash',
    'bank'
  )
  ORDER BY name;

Expected:
  ✅ Accounts Payable → liability
  ✅ Bank → asset
  ✅ Cash → asset
  ✅ Inventory → asset
  ✅ VAT Input → asset

Check ledger balance:

  SELECT 
    coa.name,
    coa.type,
    SUM(le.debit - le.credit) as balance
  FROM ledger_entries le
  JOIN coa ON le.account_id = coa.id
  WHERE coa.name = 'Accounts Payable'
  GROUP BY coa.id, coa.name, coa.type;

Expected for liability:
  ✅ Positive balance = you owe money
  ✅ Negative balance = supplier owes you
